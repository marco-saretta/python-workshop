# Git Recap

Software development requires a safe way to track changes in code.

**Version control** helps you answer:

- Who changed the code?
- When was it changed?
- What was changed?
- Can we revert to an earlier version?

Git is the tool we use to manage version control.

For a deeper explanation:
https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F

## Git vs GitHub

It is important to understand the difference:

- **Git** → A version control tool installed on your computer.
- **GitHub** → A website that hosts Git repositories online.

In this course, we use:

- Git locally (in the terminal)
- GitHub to store and share code

You are expected to create a public GitHub repository and use Git to upload your work.
